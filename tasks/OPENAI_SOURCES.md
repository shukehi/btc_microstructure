# Codex 使用方式的官方资料

核验日期：2026-10-10。以下为OpenAI官方文档或由原官方开发者页面跳转到的ChatGPT Learn页面。界面、权限项和版本会更新，开始使用时以实际安装版本为准。本文件是操作参考，不是本项目已在Codex执行的证据。

| 主题 | 官方页面 | 本交接包引用用途 |
|---|---|---|
| 快速开始 | https://developers.openai.com/codex/quickstart | 桌面打开文件夹、选择Codex；云端环境入口 |
| CLI | https://developers.openai.com/codex/cli | 在项目目录运行Codex、登录、检查本地文件和运行命令 |

本包没有预设API密钥、账号套餐、当前模型名称或付费额度。Codex账号登录和币安公共行情程序的权限是两件事。
